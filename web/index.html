Interactive Ricci Flow

Connecting…
Web demo: Python runs in your browser, on small graphs. For the real datasets, larger graphs and live steering shared between several people, clone the repository and run ./run.sh.
How to use
Click
select a node or link
Shift + click
add to or remove from the selection
Shift + drag
select everything in a box
Drag a node
move it (and the selection); it stays pinned
Double-click a node
unpin its position
Drag empty space / wheel
pan / zoom
N Add mode
click to add a node, drag node → node to link
Space / S
run or stop the flow / one iteration
[ / ]
pull the selection together / push it apart
P
pin or unpin the selection's links
Shift+P
unpin all links and nodes
A / D
increase / decrease load
Delete
remove the selection
Esc / F
clear selection / fit view

Links: colour is curvature (red negative, blue positive), dots mean the flow has stretched the link, purple means pinned. Node colour is the found community, the ground truth, or the editor group.
